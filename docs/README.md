# Documentation Index

## Current MVP Docs

Các tài liệu này phản ánh trạng thái hiện tại của dự án Health/InBody Multi-Agent RAG MVP:

- `../README.md`: tổng quan dự án, kiến trúc Multi-Agent RAG MVP, phạm vi hiện tại và roadmap.
- `../backend/README.md`: cách chạy backend, endpoint, response contract có `agent_trace`.
- `../frontend/README.md`: cách chạy Streamlit frontend và hiển thị agent trace.
- `test.md`: bộ câu test/demo cho Multi-Agent RAG MVP.
- `backend/AI_AGENT_REACT_EXPLAINED.md`: giải thích LangGraph multi-agent flow.
- `backend/FASTAPI_CONCEPTS_EXPLAINED.md`: contract FastAPI hiện tại.
- `backend/CELERY_TASKS_EXPLAINED.md`: task async/indexing và cách chat async gọi multi-agent.

## Legacy / Reference Docs

Một số tài liệu trong `datapipeline/`, `finetune/` và các ghi chú embedding cũ vẫn còn nhắc dataset pháp lý vì dự án ban đầu được fork/chuyển hướng từ prototype legal chatbot. Những file đó nên được xem là tài liệu tham khảo kỹ thuật, không phải mô tả sản phẩm MVP hiện tại.

Khi viết báo cáo hoặc demo, ưu tiên nhóm **Current MVP Docs** ở trên.
