## Sửa và kiểm tra

- `GET /me/profile` và các route cá nhân lấy subject từ JWT đã kiểm chữ ký, issuer, audience, `iat`, `nbf`, `exp`, `jti`; `X-Dev-User-Id` chỉ hoạt động khi `AUTH_MODE=development`.
- `/auth/register` tạo user với consent false. `/auth/login` kiểm Argon2id; rate limit dùng Redis chung, fail closed khi Redis vắng, giới hạn theo cặp IP/username, IP và username.
- Urgent ở `/chat/complete` với `sync_request=false` chạy fast path, không tạo task Celery. `/health/ready` kiểm PostgreSQL, Redis, Qdrant, embedding khi bật; trả 503 nếu dependency cần thiết vắng.
- Frontend production hiện form đăng nhập/đăng ký, giữ access token trong bộ nhớ phiên tab, logout xóa token và state. Demo, dev header, DevTools và thay đổi API URL bị tắt ở production. Profile không tự gán consent/giới tính/chiều cao; goal đọc/ghi `/me/goals/current`; số đo thiếu id/thời gian/weight/height không bị biến thành số giả.
